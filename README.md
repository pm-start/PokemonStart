# PokemonStart v0.53.6

## おしらせ

- シンオウのお話は、いまは はつでんしょ までです。続きはこれからのアップデートで追加します
- このバージョンから野生のポケモンの並びが変わります
- 前のバージョンのセーブで「つづきから」を選ぶと、最後に回復した場所から始まります

配布ファイルは PokemonStart_v0.53.6.pks です。

## 0.53.0へ更新するとき

セーブの保存形式が変わりました。元のセーブを別の場所に保管し、同梱の「セーブデータ移行ツール.html」で新しい形へ変換してから使ってください。
古い版へ戻す場合も移行ツールを使ってください。古い版で扱えない技などは、確認画面の案内に従って変換する必要があります。

今回はビルドとパッチの適用一致を確認しています。最終ROMのゲーム内動作確認は行っていません。


ジョウト地方への通常移動を一時停止しています。船・そらをとぶ・ゆうらん・地方間の徒歩移動ではジョウトへ行けません。ほかの地方への移動は維持しています。

そらをとぶの演出・ゆうらん、道具9999個、メニューの並べ替えを追加しました。ゆうらんは地方のバッジ8個で解禁します。

## 項目の並べ替え

スタートメニューを開いた状態でSTART、設定画面ではSELECTで並べ替えを始めます。上下で移動し、AまたはSELECTで確定、Bで取り消します。通常のスタートメニューを閉じる操作はBです。並びを保存するには、ゲーム内で通常のレポートを書いてください。

## セーブデータ

所持数の拡張でセーブの構造は変更していません。旧版は999個を超える数量の表示・処理に対応していません。
