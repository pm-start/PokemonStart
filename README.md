# PokemonStart v0.67.2

配布ファイルは PokemonStart_v0.67.2.pks です。

## おしらせ

- 更新の前に、セーブデータのバックアップをとってください
- 0.62.3 のセーブは、そのまま続けて遊べます

## 遊ぶための mGBA

ROM が 128MB なので、新しい mGBA（rom128 の版）でしか遊べません。入手先は https://github.com/pm-start/mGBA_celio_edition/releases （いちばん新しい rom128 の版）です。古い mGBA で開くと、START を押したあとの画面で「さいしんの mGBA で あそんでください」と出て先へ進みません（壊れたわけではありません）。

## ジョウト地方について

ジョウト地方への通常移動を一時停止しています。船・そらをとぶ・ゆうらん・地方間の徒歩移動ではジョウトへ行けません。ほかの地方への移動は維持しています。

## そらをとぶ・ゆうらん

ゆうらんは、いまいる地方のジムバッジ8個がそろうと使えます。

## 項目の並べ替え

スタートメニューを開いた状態でSTART、設定画面ではSELECTで並べ替えを始めます。上下で移動し、AまたはSELECTで確定、Bで取り消します。通常のスタートメニューを閉じる操作はBです。並びを保存するには、ゲーム内で通常のレポートを書いてください。

## 道具の個数

道具の所持数の上限は9999個です。
